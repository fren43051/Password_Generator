# Password-Generator

## Descripción del Proyecto

El Generador de Contraseñas es una aplicación web diseñada para crear contraseñas seguras y almacenarlas en un historial. Esta herramienta es ideal para usuarios que necesitan generar contraseñas robustas y únicas para diferentes cuentas y servicios en línea.

## Funcionalidades Principales

1. **Generación de Contraseñas Seguras**: Permite generar contraseñas de entre 8 y 30 caracteres, incluyendo letras mayúsculas, minúsculas, números y símbolos especiales.
2. **Validación de Fortaleza**: Evalúa la fortaleza de la contraseña generada y proporciona retroalimentación visual sobre su seguridad.
3. **Historial de Contraseñas**: Almacena las contraseñas generadas en un panel de historial para referencia futura.
4. **Copia al Portapapeles**: Facilita la copia de contraseñas al portapapeles con un solo clic.
5. **Interfaz Intuitiva y Responsiva**: Ofrece una interfaz de usuario amigable y adaptativa para una experiencia de usuario óptima.

## Tecnologías Utilizadas

- **HTML**: Para la estructura de la aplicación web.
- **CSS**: Para el diseño y la presentación visual.
- **JavaScript**: Para la lógica de generación de contraseñas, validación de fortaleza y gestión del historial.

## Características Destacadas

- **Seguridad**: Genera contraseñas que cumplen con los estándares de seguridad recomendados.
- **Usabilidad**: Interfaz sencilla y fácil de usar, adecuada para todo tipo de usuarios.
- **Portabilidad**: La aplicación es accesible desde cualquier dispositivo con un navegador web.
- **Eficiencia**: Generación rápida de contraseñas y gestión eficiente del historial.

## Cómo Usar la Aplicación

1. **Ingresar la Cantidad de Caracteres**: Especifica la longitud deseada para la contraseña (entre 8 y 30 caracteres).
2. **Generar Contraseña**: Haz clic en el botón "Generar" para crear una nueva contraseña.
3. **Verificar Fortaleza**: Observa la retroalimentación sobre la fortaleza de la contraseña generada.
4. **Copiar Contraseña**: Utiliza el botón de copia para guardar la contraseña en el portapapeles.
5. **Historial**: Accede al panel de historial para ver las contraseñas generadas anteriormente.

Esta aplicación es una solución completa para la generación y gestión de contraseñas seguras, diseñada para mejorar la seguridad en línea de los usuarios.
